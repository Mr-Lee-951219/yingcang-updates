# 映仓更新通道

本仓库用于映仓 Windows 桌面版的版本检查和客户更新分发。

当前版本：**0.2.4**。

软件启动后会在后台检查新版本。0.2.3 及之后版本发现更新会弹出提示框，也可通过“设置 → 关于映仓”手动检查、下载，并确认重启安装。客户检查和下载更新无需登录 GitHub。

0.2.1 及之后版本均保留软件内升级能力。更新信息验证数字签名，程序包验证 SHA256，升级保留本机账号、设置和媒体文件。检查和下载需要网络能够访问 GitHub。

## 当前版本更新

新增：任务搜索与勾选批量操作、回收站恢复、监控编辑、开播提醒与自动录制、脱敏诊断。

修复：好友主页无法返回好友列表。

公开发行只包含编译后的客户更新包和校验文件。应用源码及源码附件保存在私有仓库。
