# 映仓更新通道

本仓库用于映仓 Windows 桌面版的版本检查和更新分发，不包含应用源码。

当前版本：**0.2.1**。

在软件内打开 **设置 → 关于映仓 → 检查更新**。版本检查不需要登录 GitHub；发现新版本后，由使用者决定是否下载和重启安装。

更新信息使用数字签名，程序包按签名清单中的 SHA256 校验。更新期间保留本机账号、设置和已保存媒体。

当前通道仅提供签名的版本信息，尚未公开程序更新包。程序包通过公开发行检查后再发布。网络无法连接 GitHub 时，检查和下载可能失败，可稍后重试。

`latest.json` 是供软件读取的签名版本清单，请勿手工修改其内容。
